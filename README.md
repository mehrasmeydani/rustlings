# Rustlings: my Rust practice

My working copy of [**Rustlings**](https://github.com/rust-lang/rustlings), the official set of small exercises for learning Rust by fixing code that doesn't compile or pass its tests yet. I'm using it to build solid Rust fundamentals alongside my Rust web projects.

**Progress: 89 of 94 exercises done.** I'm currently on `using_as`, in the last chapter (conversions).

## What's covered

| # | Topic | # | Topic |

| 00 | Intro | 12 | Options |

| 06 | Move semantics | 18 | Iterators |
| 07 | Structs | 19 | Smart pointers (`Box`, `Rc`, `Arc`, `Cow`) |
| 08 | Enums | 20 | Threads |
| 09 | Strings | 21 | Macros |
| 10 | Modules | 22 | Clippy |
| 11 | Hash maps | 23 | Conversions (`as`, `From`, `TryFrom`, `AsRef`, `FromStr`) |

The chapters are broken up by quizzes that combine the topics covered so far.

## Layout

```
exercises/   my solved exercises, one folder per chapter
solutions/   the reference solutions Rustlings unlocks after each exercise
Cargo.toml   one binary per exercise (generated by Rustlings)
```

## Running it

```bash
cargo install rustlings
rustlings          # opens the interactive watch mode at the next unsolved exercise
```

Every exercise is also a binary, so each one can be run on its own, for example `cargo run --bin iterators1`.
